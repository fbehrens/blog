# Sketchbook Resources

## Knowledge

- [Sketchbook Help Center](https://help.sketchbook.com/)
  Official docs from Sketchbook Inc. Use for: any UI, menu path, or feature question.
- [Getting Started on iPad and Android Tablets (Sketchbook blog)](https://sketchbook.com/blog/getting-started-on-tablets)
  Official tour of the Double Puck, brushes, layers, saving. Use for: first-week orientation.
- [Gestures (Sketchbook Help)](https://help.sketchbook.com/docs/gestures)
  Full list of 2- and 3-finger gestures. Use for: undo/redo/zoom/full-screen.
- [Basic UI elements (Sketchbook Help)](https://help.sketchbook.com/docs/basic-ui-elements)
  Phone vs tablet UI, corner tools, marking menu. Use for: "where is X on my phone?"
- [Connecting styluses for mobile users](https://help.sketchbook.com/docs/connecting-styluses-for-mobile-users)
  S Pen is the supported Android stylus; Pen Mode. Use for: pressure, palm rejection.
- [Saving files](https://help.sketchbook.com/docs/saving-files) / [Exporting images](https://help.sketchbook.com/docs/exporting-images)
  Save, autosave timer, Share/Export formats. Use for: getting drawings out of the app.
- [Text](https://help.sketchbook.com/docs/text) / [Importing images](https://help.sketchbook.com/docs/importing-images)
  Use for: comic bubbles on photos (lesson TBD — not yet verified).
- [Samsung: AirDrop support in Quick Share on Galaxy S26](https://www.samsung.com/hk_en/news/product/samsung-brings-airdrop-support-to-quick-share-with-galaxy-s26-series/) and [SamMobile how-to](https://www.sammobile.com/news/how-to-share-files-galaxy-phone-iphone-ipad-macbook/)
  Use for: phone → Mac transfer.
- [Apple: Use AirDrop on your Mac](https://support.apple.com/guide/mac-help/mh35868/mac)
  Use for: Mac receiving settings, Downloads folder.
- [Claude Code docs: Work with images](https://code.claude.com/docs/en/common-workflows#work-with-images)
  Use for: drag-drop, paste, or path to give an image to Claude.
