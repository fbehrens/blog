Cheat sheet

The opencode module shape

Every domain module in opencode follows this skeleton. Copy it.

The skeleton

import { Context, Effect, Layer } from "effect"

// 1 · INTERFACE — the public surface
export interface Interface {
  readonly doThing: (arg: A) => Effect.Effect<Out, Err>
}

// 2 · TAG — identity + the type you yield*
export class Service extends Context.Service<Service, Interface>()("app/Name") {}

// 3 · LAYER — build once; deps live in slot 3 of the type
export const layer: Layer.Layer<Service, never, Dep> = Layer.effect(
  Service,
  Effect.gen(function* () {
    const dep = yield* Dep                       // acquire deps ONCE
    const doThing = Effect.fn("Name.doThing")(function* (arg) { /* ... */ })
    return Service.of({ doThing })
  }),
)

// 4 · DEFAULT LAYER — deps pre-provided, ready to run
export const defaultLayer = layer.pipe(Layer.provide(Dep.defaultLayer))

The namespace export (index.ts)

// re-export the whole module under one name
export * as Discovery from "./discovery"
// callers write:  Discovery.Service, Discovery.layer, Discovery.defaultLayer

Compose them (the AppLayer — lesson 2)

export const AppLayer = Layer.mergeAll(
  Skills.defaultLayer,
  Config.defaultLayer,
  Storage.defaultLayer,
)
// then: const runtime = ManagedRuntime.make(AppLayer)

Decoder ring

Context.Service<Self, Iface>()("id")make a service tag (identity you yield*)
Layer.effect(Tag, eff)build an impl that needs effects/deps to construct
Layer.succeed(Tag, value)build an impl from a plain value (no deps)
Layer.provide(L2)satisfy a layer's deps using another layer
Layer.mergeAll(...)combine sibling services into one layer
Effect.fn("Name.op")(gen)named effect = a span (free telemetry)
Service.of({...})type-checked construction of the interface
yield* Serviceget the implementation inside an Effect.gen
