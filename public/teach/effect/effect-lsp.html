Effect language service

@effect/language-service — a TypeScript plugin that adds Effect-aware diagnostics, refactors, and type display.

Setup (per project)

# 1 · install
bun add -d @effect/language-service

# 2 · tsconfig.json — register the plugin
{ "compilerOptions": { "plugins": [{ "name": "@effect/language-service" }] } }

# 3 · VSCode — use the WORKSPACE TypeScript (bundled TS won't load plugins)
#    .vscode/settings.json:
{ "typescript.tsdk": "node_modules/typescript/lib",
  "typescript.enablePromptUseWorkspaceTsdk": true }
The one gotcha The plugin only loads under the workspace TypeScript. In VSCode run Cmd-Shift-P → "TypeScript: Select TypeScript Version" → "Use Workspace Version". Confirm with "TypeScript: Open TS Server log" or just hover an Effect value — you'll see the three-slot Effect<A, E, R> rendered nicely.

Editor-only vs CLI

A TS language-service plugin runs only while editing. Plain tsc (and CI) won't see Effect diagnostics. To get them at build time, patch the local compiler: 

bunx effect-language-service patch     # patches node_modules/typescript
# make it stick across installs — package.json:
{ "scripts": { "prepare": "effect-language-service patch" } }

After patching, tsc --noEmit emits Effect warnings/errors too. Tune exit-code behavior in tsconfig under the plugin's options (e.g. ignoreEffectWarningsInTscExitCode).

Diagnostics you'll meet early

floatingEffectAn Effect value created but never yield*'d or run — it does nothing. Usually a bug.
multipleEffectProvideChained Effect.provide(a) then Effect.provide(b). Merge into one layer instead: Effect.provide(L.pipe(Layer.provide(dep))) — protects scoped-layer lifecycle.
globalFetchUsing global fetch instead of Effect's HttpClient.
redundantSchemaTagIdentifierRepeating the tag string in Schema.TaggedError("X")("X", …) — drop the duplicate.

Other powers

  • Quick-info shows Effect<A, E, R> with the success / error / requirement channels split out.
  • Refactors: wrap in Effect.gen, add a missing yield*, convert pipe↔gen.
  • "Go to definition" on an RpcClient resolves to the Rpc definition.
